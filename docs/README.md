# Letter Bag documentation

This directory contains Letter Bag implementation handoffs and submission writing.

- [DailyTracker website integration](wordbag.md)
- [Devpost project story](devpost-project-story.md)

In these documents, **Confirmed** means a requirement established by the current game or the owner's request. **Proposed** means a suggested implementation choice. **Open** means the website owner needs to decide before that part is built. Decision and question IDs use `DLB-WEB-D#` and `DLB-WEB-Q#` and are never reused.
